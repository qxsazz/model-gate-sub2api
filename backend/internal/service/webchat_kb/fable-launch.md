# 模型上新｜Anthropic 满血官 Key 分组新增 fable5.2

ModelGate 的 Anthropic 满血官 Key 分组现已接入 `fable5.2`。

可以使用对应分组的 API Key，在客户端刷新模型列表后选择 `fable5.2`。客户端支持手动填写模型时，也可以直接填入 `fable5.2`。

如果接入时遇到报错，可以在技术交流群反馈客户端名称和报错信息。发截图或日志前，请记得给 API Key 打码。

来源为 [ModelGate 站内公告](https://www.model-gate.cc/)，公告 ID 为 34。
