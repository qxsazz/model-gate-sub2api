# 模型与分组

选择分组，是选择请求所经过的渠道、可用模型范围和计费规则，而不只是选择一个折扣数字。

## 普通分组与专属分组

| 类型 | 使用方式 | 倍率规则 |
| --- | --- | --- |
| 普通分组 | 按账户和密钥权限使用 | 参与成长优惠的分组按 VIP 档位减免 |
| VIP 候选专属分组 | 达到门槛并获得对应资格后选择 | 独立定价，不再叠加普通组减免 |
| 人工授权分组 | 按管理员单独授予的资格使用 | 按该分组及人工定价规则执行 |

不同分组的渠道和模型能力可能不同。部分私人、测试或订阅分组不会自动授予 VIP 用户；专属身份不意味着所有专属分组都可访问。

## 查看模型

使用该密钥请求 `/v1/models`，并结合控制台的分组说明与公告选择模型。不要依据旧文档中的模型名或别人的截图创建请求。

## 选择接入协议

Claude Code 主要使用 Anthropic Messages，Codex 使用 Responses，其他客户端可能使用 Chat Completions。模型、渠道和协议应同时匹配。

## 升级后如何使用

VIP 权益可以改变符合条件的有效倍率和访问资格，但不会自动切换现有 API Key 的分组。进入 API 密钥页面核对可选分组，再选择或创建对应密钥。

先用小请求验证连接，并查看使用记录确认当前使用的是预期模型与倍率。详细规则见 [VIP 等级与权益](/docs?cat=membership&page=vip)。
