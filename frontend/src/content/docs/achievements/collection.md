# 充值与收藏成就

**敬请期待。** 充值荣誉和收藏成就不会取代现有 VIP 权益。

## 充值荣誉

保留三档长期充值成就，参考规划节点为 `$1,000`、`$5,000` 与 `$10,000`。具体名称、门槛和奖励在上线前确定。

累计口径与 VIP 保持一致：实际充值及后台手动增加计入，退款与后台退费扣减；赠送、兑换和奖励不推动该类成长。

## 避免重复奖励

当前 VIP 已有五档、门槛金额 1% 的累充奖励。新增成就优先提供独立荣誉和收藏价值，不默认在同一充值节点再次承诺现金奖励。

现有奖励请查看 [累充奖励](/docs?cat=membership&page=rewards)。未来成就的退款追回、荣誉保留与重复领奖规则，另行明确。

## 收藏里程碑

保留集齐任意一个分类后的收藏荣誉，以及完成其余成就后的终章勋章。收藏需要实际解锁，而不是只浏览过文档。

实物或其他额外奖励目前不承诺；如有开放，以官方活动公告为准。
