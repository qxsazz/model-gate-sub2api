# 官方 Sub2API v0.2.19 兼容合并

## 来源与范围

- 官方稳定版：<https://github.com/Wei-Shaw/sub2api/releases/tag/v0.2.19>。
- 上游提交：`dece26153621959ccd7635814f4b2d08304e681a`（正式 release tag 对应的提交）。
- 合并前 MG 提交：`6fdae5d3b46dbe00f4b3c6c6901d366ac37e82aa`，版本为 `0.2.18-mg.5`，已验证的上游基线为 `0.2.18`。
- 升级分支：`upgrade/upstream-0.2.19`。

## 二开兼容处理

- 保留 MG 品牌、README、VIP/成就、画布、私有素材审核、分组计价、网关恢复及托管发布机制；不合入上游新增的推广内容和配套图片。
- Gemini 模型接口在所有可用账号均声明映射时，使用官方的声明模型列表；否则继续使用 MG 的多账号汇总、模型名归一、元数据保留与单账号故障隔离。
- Gemini 签名降级重试继续使用 MG 的思考参数处理，同时合入官方的可配置同账号重试次数；签名降级阶段不占用该重试预算。MG 的恢复配置与新配置并存。
- 管理员路由先执行官方受限密钥资源校验，再注册 MG 扩展接口。未登记权限的 VIP、成就、画布、提示词审计等接口默认拒绝受限密钥访问，原有管理员会话不受影响。
- 鉴权缓存版本从 MG 的 `25` 升为 `26`：官方也使用 `25` 表示新增图片计费字段，直接复用会误接收缺少该字段的 MG 旧快照。新增回归覆盖缓存往返、旧缓存淘汰，以及图片计费与原有利润、倍率、Fast 策略共存。
- 保留 MG 已升级的 `golang.org/x/image v0.45.0`，同时合入官方更新的 crypto、net、sync、term、sys、text、tools 版本，不降低已有依赖版本。
- 模型同步组件保留官方并发/过期请求保护，并补齐错误消息提取函数的导入。
- 已应用的 SQL 迁移不改名、不改内容；官方 `247_scoped_admin_api_keys.sql` 和 `248_group_image_count_billing.sql` 作为新增文件执行。迁移回归同时检查 MG VIP 与官方 Gemini 生图迁移仍保留在记录中。

## 行为变化与升级注意

- 新建管理员密钥改为按操作、资源范围、期限和 IP 授权，仅保存摘要。已有旧版全权密钥仍兼容，轮换和删除需要管理员 JWT 会话及二次验证；不再新建旧版全权密钥。
- OpenAI/Composite 分组新增图片按张计费开关，默认关闭；开启后只对专用图片端点按实际返回的图片数结算。渠道按次图片价继续保留 token 用量用于分档，分组和 VIP 倍率仍沿原计费流程处理。
- Gemini 默认目录移除已停用的 2.x 与 `gemini-3-pro-preview`；手工配置的白名单、模型映射继续支持这些模型。连接测试默认使用 `gemini-3.5-flash`。
- `gateway.max_same_account_retries_gemini` 默认 `4`，范围 `0–10`；`0` 表示不对瞬时上游错误同账号重发。
- 支持 GPT-6.1 Terra；修复 DeepSeek Pro 定价、缓存读取 token、OpenCode developer 角色兼容，以及国产 Coding Plan 频率型 429 的短冷却。
- Grok 新增模型目录诊断和持久化快照保护；多种转换路径记录原始响应模型。
- 超过单个 multipart 部分 50 MiB 的图片上传直接拒绝，不再截断；分页溢出、管理员保护规则状态码、渠道搜索配置和模型广场定价按官方修复。

## MG.2 调度并发槽位修复

测试部署版本为 `0.2.19-mg.2`，同时包含上述官方兼容升级和 P1 修复。

- `GatewayService.newSelectionResult` 在账号信息回填失败时，释放已取得的并发槽位；成功返回后仍由调用方释放，未取得槽位的等待计划不执行释放。
- 沿用现有释放函数的独立后台超时上下文，客户端取消后仍能清理槽位，不改变选号、优先级或重试策略。
- 新增 Anthropic/Gemini 公开选号入口回归，验证账号回填失败、取得槽位后取消、正常请求结束及槽位立即复用；同时覆盖等待计划和缺失释放函数的错误路径。
- P1 修复后，154 个调度相关测试通过，共 206 个测试及子测试；回填相关单独回归的 12 个测试也全部通过。
- 测试部署前的安全扫描发现 `vue-i18n 9.14.5` 受高危 XSS 公告 [GHSA-83rm-6c8r-g728](https://github.com/advisories/GHSA-83rm-6c8r-g728) 影响。官方已停止维护 v9/v10，因此将运行时与消息编译器同步升级至 `11.4.16`，保留 Composition API、语言懒加载和 CSP 运行时入口。前端 CI 使用 Node 24，与镜像构建一致并满足新版依赖的 Node 22+ 要求。
- 新增实际语言模块的中英文加载、参数插值和英语复数选择回归；依赖审计沿用已有规则，通过验证，不增加漏洞豁免。
- P2（OpenAI 旧缓存覆盖数据库终检结果）仍待修复，不属于此次 P1 改动。
