# 常见问题

这里汇总 Model-Gate 接入过程中最常见的问题。

## 为什么返回 401？

检查 API Key 是否完整、是否已撤销，以及请求头是否使用 `Bearer` 格式。环境变量更新后通常需要重新打开终端或重启客户端。

## 为什么提示模型不存在？

模型名称可能输入错误，或当前账户不可用。请重新查询 `/v1/models`，使用返回的准确标识。

## Base URL 应该填写什么？

OpenAI 兼容客户端通常填写 `https://model-gate.cc/v1`；某些客户端会自行追加 `/v1`，此时应按客户端说明调整，避免路径重复。

## 为什么请求很慢？

响应时间会受到模型、输入长度、网络和上游负载影响。先用短请求测试，并检查是否存在代理、反复重试或过高并发。

## 遇到 429 怎么办？

降低并发，采用有限次数的指数退避。不要立即并行重试大量请求。

## 如何安全地寻求帮助？

提供发生时间、状态码、客户端版本和脱敏日志。请删除完整 API Key、个人信息和敏感请求正文。
