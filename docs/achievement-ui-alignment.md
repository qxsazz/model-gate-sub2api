# 成就页与确认预览的对齐清单

视觉与交互基准：已确认的独立本地预览 `achievement-ui-preview`。正式页面继续使用项目统一 AppLayout；账户日期、VIP、金额、进度、卡片和回执读取真实接口。

| 区域 | 原先差异 | 对齐结果 |
| --- | --- | --- |
| 内容样式 | 手工近似的间距、颜色和布局 | 本地内容样式按页面范围迁入，不修改其他模块 |
| 图标 | 多处图标遗漏或只使用文字箭头 | 沿用本地 SVG 路径：太阳、书本、箭头、复制、任务、奖励与关闭 |
| 当前佩戴 | 英文标记、统计顺序、缺少快捷入口 | 当前佩戴、查看徽章；已解锁、待领奖励、补签卡及对应入口 |
| 分类与系列 | 系列金额占用大卡，使用内部术语 | 原版分类与紧凑系列摘要，保留真实金额资格和领取操作 |
| 签到主卡 | 标题与时间排版不一致，缺少陪伴短句 | 标题/金额同行、三项统计、相遇日期、下一枚徽章、Token提示与陪伴短句 |
| 数字与面板 | 数字字体不同，深色背景被覆盖 | 金额与相伴数字同样式；五块面板统一暖色，两组卡片上下对齐 |
| 日历 | 普通日期缺少说明弹窗 | 全部日期打开「这一天的签到」，含农历、状态、书本/勾选及太阳提示 |
| 日期状态 | 今日、未来、已签到及范围外缺少说明 | 显示各自说明；今日可签到，有效漏签才核验历史权益并补签 |
| 月份与标记 | 缺少完整图例 | 已签到/可补签/选中日期图例、背景、月份浏览；不扩大补签有效范围 |
| 日期小笺 | 印章、排版、收尾文案不齐 | 农历/星期、Token宜忌、柔金与柔铜印章及原版收尾文案 |
| 星座能量签 | 符号、关键词、日期、小太阳及说明缺失 | 圆形符号、关键词、日期、主文案、太阳建议框与趣味参考说明 |
| 相伴小记 | 普通文字框，缺少书本印记 | 原版书本圆标、标题与回顾；天数和徽章数来自真实账户 |
| 徽章列表 | 操作拥挤、任务入口不一致 | 阶段、状态、名称、条件、进度、奖励图标和主要操作；介绍仅在详情 |
| 徽章详情 | 信息散列、无完整操作区 | 原版详情头、诗意说明、四行信息及任务/领取/佩戴；失败在弹窗内显示 |
| 活动任务 | 两列大卡，与预览任务行不同 | 图标、名称、简介、已通过标记、题数与开始挑战组成紧凑任务行 |
| 任务筛选 | 无收起操作 | 收起/显示已通过；切换类别恢复显示；查看任务定位对应目标 |
| 下一目标 | 缺少阶段节点和系列说明 | 实际下一徽章、阶段节点、剩余主题数、补签卡及系列金额说明 |
| 篇章 | 指定任务混在全部主题中 | 初航四项任务单列并直达练习；后两篇章仍为预告 |
| 答题 | 进度段、选项字母和结果动作不齐 | 逐题、进度段、题号、A/B/C、完成数量、翻页、结果与重新挑战 |
| 操作反馈 | 顶部消息推动整个布局 | 反馈浮层；回执和金额原因保留，弹窗失败支持同次重试 |
| 手机与深浅色 | 独立拼凑的断点和徽章尺寸 | 预览布局与背景、明确徽章尺寸；活动横滑，页面无横向溢出 |

## 正式数据的必要状态

补签卡入口已去重：删除额外的「补上遗漏，继续前行」模块，数量由原有概览和签到卡展示，操作通过日历完成，获取与使用记录继续保留。

- 未选择时不猜测星座，明确选择后按账户保存，可清空，不收集生日。
- 金额资格、预算、历史权益不足时展示真实原因，不把已解锁写成必定可领取，不展示未核验金额。
- 签到/补签沿用服务端校验与原子入账；日期说明和 Token 提示不产生自动计费调用。
- 原徽章 PNG 与 `MedalArt.vue` 裁剪坐标不变，21 枚诗意文案使用已确认版本。

验收覆盖桌面、手机、两种主题、五种日期状态、答题与奖励失败/响应丢失；真实数字与示例数字不要求相同。
