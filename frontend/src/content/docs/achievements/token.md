# Token 成长成就

付费文本调用会累积到这六档徽章。打开「成就与签到」即可查看当前进度和下一档门槛。

## 六档用量里程碑

| 徽章 | 累计 Token | 默认成就奖励原额 |
| --- | --- | --- |
| 星火 | 100 万 | $0.10 |
| 星芒 | 1,000 万 | $0.50 |
| 星轨 | 1 亿 | $2.00 |
| 星河 | 10 亿 | $8.00 |
| 星海 | 100 亿 | $25.00 |
| 星门 | 1,000 亿 | $80.00 |

解锁后就可以佩戴徽章。金额奖励开放时，页面会显示账户的领取资格。

## 统计口径

从本功能发布后累计，以成功提交的付费文本计费事务为准。输入、输出、缓存读取与缓存创建四个互斥 Token 桶只相加一次；计费重试不会重复增长。

显式图片、视频和未计费调用不计入，历史使用日志不自动回填。当前记录不是所有历史 API 用量之和。

## 展示与奖励

每枚徽章的奖励需手动领取，每个账户限领一次。到账前会先抵扣已有的待追回金额。VIP 等级按有效充值计算。
