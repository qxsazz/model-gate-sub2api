# 工具选型指南

选择与你的工作方式一致的工具，再核对协议、模型与分组。支持自定义服务商，不等于每项高级功能都已在 MODEL-GATE 完成兼容测试。

## 按场景选择

| 场景 | 优先了解 | 接入关注点 |
| --- | --- | --- |
| 桌面多模型聊天 | Cherry Studio | 自定义服务商、模型列表与附件能力 |
| 编辑器内编程 | Cline、Continue、Cursor | 协议、工具调用与代码访问权限 |
| 终端代码协作 | Claude Code、Codex、OpenCode、Aider | 服务商配置、模型能力与操作审批 |
| 管理多套配置 | CC Switch | 配置备份、生效位置与切换后的凭据 |

## CC Switch · 配置管理

适合需要管理多套 Claude Code 或 Codex 配置的用户。先备份已有配置，再添加 MODEL-GATE 服务地址和密钥；切换后验证实际生效的服务商与模型。

配置管理工具不提供本站额度，也不会自动授予 VIP 分组权限。

[官方项目与使用说明](https://github.com/farion1231/cc-switch)

## Cherry Studio · 桌面客户端

适合日常对话与多模型工作流。选择与分组匹配的服务商类型，填写地址、密钥和模型。OpenAI 兼容类型通常使用 `https://model-gate.cc/v1`；不同客户端对地址补全的方式可能不同。

先验证文本对话，再尝试图片、文件或其他能力。确认聊天记录和同步功能的数据保存位置。

[官方项目与下载入口](https://github.com/CherryHQ/cherry-studio)

## Cline · 编程助手

适合在编辑器中进行代理式代码任务。官方支持自定义兼容 API；配置时核对 Base URL、模型 ID 和工具调用能力。

保持文件修改、终端执行与外部访问审批，不因使用第三方网关而放宽权限。首次接入先完成只读任务。

[官方网站](https://cline.bot/)

## Continue · 编辑器模型配置

适合按任务配置对话、编辑等模型角色。官方配置支持 OpenAI 兼容服务；`apiBase`、模型与凭据需要与实际分组匹配。

对话可用不表示补全、嵌入或重排序也可用，不为未开放的能力填写未经确认的模型。

[官方配置参考](https://docs.continue.dev/reference)

## OpenCode · 终端编程

适合希望自定义服务商的终端用户。官方支持配置 provider 与 `baseURL`。选用与分组对应的协议，不同时让工具和网关重复追加相同路径。

设置完成后通过小任务和使用记录验证，保留工具自己的权限策略。

[官方服务商文档](https://opencode.ai/docs/providers/)

## Aider · 终端代码协作

适合以代码仓库为中心的终端协作。官方提供 OpenAI 兼容 API 配置说明；接入前确认目标模型适用于任务以及支持的接口。

修改前保持 Git 工作区可追踪，核对自动提交和文件编辑相关配置。

[官方兼容 API 指南](https://aider.chat/docs/llms/openai-compat.html)

## 进一步了解

OcHub、OpenClaw、Hermes Agent 保留在扩展候选清单中。它们的接入、权限和版本兼容尚需分别核对，本版不提供已验证兼容的承诺。

Claude Code、Codex 和 Cursor 的独立教程位于左侧客户端接入栏目。工具版本持续变化，下载与安装始终优先查阅官方说明。

## 接入前检查

1. 创建独立的工具密钥，不与其他应用共用。
2. 核对协议、模型与分组，而不只是确认域名。
3. 查看工具是否同步凭据、上传日志或读取整个代码仓库。
4. 用少量请求验证，再启用批量或自动化任务。
