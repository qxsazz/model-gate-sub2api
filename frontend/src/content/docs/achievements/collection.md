# 充值与收藏成就

收藏册中有三档充值荣誉。累计有效充值达到门槛后，可以佩戴对应徽章。

## 充值荣誉

| 徽章 | 累计有效充值门槛 | 默认成就奖励原额 |
| --- | --- | --- |
| 千金铭记 | $1,000 | $10.00 |
| 恒金之印 | $5,000 | $50.00 |
| 万金典藏 | $10,000 | $666.00 |

充值成长按实际充值和后台充值累计，退款会扣减。加赠、兑换和奖励余额不计入成长。

## 与 VIP 累充奖励的关系

收藏册会显示每枚徽章奖励的领取条件，每个账户限领一次。VIP 中心另有五档[累充奖励](/docs?cat=membership&page=rewards)，分别领取。

## 退款与收藏状态

退款或后台退费使有效充值低于门槛时，对应荣誉锁定，佩戴撤下，已领取奖励按原额追回。余额不足及此前用于抵扣欠款的部分形成待追回金额，后续入账可抵扣。

重新充值达到同一门槛后，荣誉可以恢复。已经领取并被追回的那一档金额不会再发放。
