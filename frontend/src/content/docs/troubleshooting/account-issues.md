# 账户、充值与 VIP 问题

网站操作与模型 API 使用不同的入口及凭据。先核对报错发生在哪个页面，再查看业务消息。

## 登录失效或刷新失败

网站 401 可能是登录会话过期或无效，前端会尝试刷新会话；刷新凭据失效时可能返回登录页。重新登录网站，不需要因此替换所有模型 API Key。

如果刷新接口出现网络错误、429 或 5xx，也可能是暂时不可用，并非密码错误。等待恢复或反馈，不反复修改密码来处理网络故障。

## 支付完成但余额未更新

核对订单状态、环境、支付币种与账户。短暂确认延迟时先刷新订单，长时间异常则提供脱敏订单号、时间与状态。

不要连续重复付款，也不要把 API 的 403 或计费服务 503 直接当成充值失败。模型调用还可能受到密钥预算、分组或订阅限制。

## VIP 等级、分组或奖励不符合预期

| 现象 | 排查方向 |
| --- | --- |
| 有余额却没有升级 | 成长看累计有效充值，不是余额；兑换、赠送和奖励不计入 |
| 会员标识与充值等级不一致 | 可能存在人工授权，分别核对成长等级和有效权益 |
| 升级后旧密钥仍用普通分组 | 不会自动替换密钥分组，需要选择已获授权的分组 |
| 专属分组返回 `GROUP_NOT_ALLOWED` | 核对退款、退费或人工调整后的有效资格 |
| 奖励领取返回 400 | 查看 `reason`；`VIP_REWARD_THRESHOLD_NOT_REACHED` 表示实际成长金额未达到门槛 |
| 奖励功能关闭或账户不可用 | 阅读当前业务消息，刷新状态；不能靠反复点击绕过限制 |
| 奖励曾被追回，充值后仍不能再领 | 每档仅发放一次，被追回后保留历史领取记录 |

2% 累充奖励与成就系统是不同功能。测试环境「成就与签到」读取真实记录，但现金默认关闭，按管理员核验名单、近期活动资格与预算开放。签到没有到账时查看回执原因和待追回金额抵扣；同日开通或升级不补发。补签、盲盒与后续篇章预告尚未开放。详见 [签到与全勤](/docs?cat=achievements&page=check-in)。

## 兑换码失败

核对大小写、完整性、使用次数与适用条件，读取响应中的业务说明。兑换码用于对应权益，不是 API Key；兑换后的余额也不自动等同于有效充值额。

## 错误记录入口报 403

`Error requests view is disabled` 表示用户错误记录功能可能未开放。它与模型调用的 `GROUP_NOT_ALLOWED` 或余额不足不是同一问题。查看页面实际开放入口，必要时按 [反馈模板](/docs?cat=troubleshooting&page=records)说明情况。

## 查不到网站操作日志

操作日志属于管理端。普通用户可以查看自己开放的订单、使用记录、错误记录和 VIP 状态；需要进一步查询时，由平台核对管理端日志，不能要求用户绕过权限访问后台。
