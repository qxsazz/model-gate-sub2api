# Token 成长成就

**敬请期待。** 用每一次调用，积累长期成长记录。

## 三档用量里程碑

保留从初阶到高阶的累计 Token 成长玩法。参考规划档位为 10 亿、100 亿和 1,000 亿 Token，用于形成长期收藏目标，不是当前可领取奖励的门槛。

| 规划勋章 | 成长方向 | 奖励状态 |
| --- | --- | --- |
| 初阶 · 星火 | 首档累计用量 | 敬请期待 |
| 进阶 · 星河 | 第二档累计用量 | 敬请期待 |
| 典藏 · 星海 | 第三档累计用量 | 敬请期待 |

## 统计口径

规划覆盖输入、输出及缓存用量；需要避免字段重叠造成重复统计。失败请求、历史数据和缓存的具体口径，在上线前明确。

## 展示与奖励

规划展示当前进度、解锁日期和获得方式，达成后在详情中手动领取一次奖励。补签卡等奖励依赖对应活动系统开放，目前不发放。

Token 成长不会直接改变充值 VIP 等级，也不建议为解锁勋章制造无意义请求。
