# Token 成长成就

测试环境已接入六档 Token 成长，用正常的付费文本调用积累长期记录。

## 六档用量里程碑

| 徽章 | 累计 Token | 默认成就奖励原额 |
| --- | --- | --- |
| 星火 | 100 万 | $0.10 |
| 星芒 | 1,000 万 | $0.30 |
| 星轨 | 1 亿 | $0.80 |
| 星河 | 10 亿 | $2.00 |
| 星海 | 100 亿 | $5.00 |
| 星门 | 1,000 亿 | $12.00 |

现金默认关闭；上述金额仅在管理员开放成就奖励、账户处于全体或名单的开放范围且满足近期活动资格时可领取，启用实时限额时还需额度充足。领奖成功即到账。已解锁徽章可以先收藏和佩戴，无需先领取现金。

## 统计口径

从本功能发布后累计，以成功提交的付费文本计费事务为准。输入、输出、缓存读取与缓存创建四个互斥 Token 桶只相加一次；计费重试不会重复增长。

显式图片、视频和未计费调用不计入，历史使用日志不自动回填。当前记录不是所有历史 API 用量之和。

## 展示与奖励

服务端核验累计进度后解锁；每枚奖励手动领取、终身一次。换戴、刷新或重复领奖请求不会增加奖励。奖励可能先抵扣账户已有的待追回金额。

Token 成长不改变充值 VIP 等级，无需为解锁徽章制造无意义请求。生产开放需在测试环境验收后单独发布。
