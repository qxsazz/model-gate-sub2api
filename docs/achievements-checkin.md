# 成就与签到：测试环境验收

本功能以已确认的虚拟背景 v2 徽章为视觉基准，入口为 `/achievements`，默认打开签到。正式功能读取认证用户的数据库记录，不使用静态原型的模拟余额或进度。

## 已实现范围

- 21 枚成就：签到 3、Token 成长 6、充值荣誉 3、活动探索 9。C02、C03 为后续篇章预告。
- 北京时间自然日签到，用户每天最多一次，原额即时入账，账户已有 VIP 待追回奖励时先抵扣，保存原额、抵扣、净到账、当日实际等级和政策修订。
- 普通会员及 VIP1–5 每日权益：$0.01 / $0.05 / $0.10 / $0.25 / $0.50 / $1.00。金额由数据库政策表提供；VIP 开关关闭时按普通会员计算，人工展示徽章不提升现金档位。
- 连续签到和最长连续记录；断签不会抹去最长连续成就。历史补签、补签卡暂不开放，不为历史日期补发现金。
- Token 进度从本功能发布后累计，以成功提交的付费文本计费事务为准。四个互斥 Token 桶相加一次，计费重试不重复增加。显式图片、视频和未计费调用不计入；历史日志不自动回填。
- 累计有效充值本金核验荣誉；奖励和加赠不计入充值。退款锁定不再满足条件的充值荣誉，已领取的荣誉奖励终身不可再领，支持余额追回和待追回金额。
- 成就奖励与佩戴分开处理，已解锁徽章可直接佩戴，换戴不再发奖。领取唯一键为账户与徽章编号。
- 活动探索包含六个知识主题和六个实践场景演练，各 10 题，答对至少 8 题通关。服务器评分并保存尝试，24 小时最多提交 30 次。通过不同主题各计一次；初识平台、接入地址、首次请求、使用成本四项通关后收藏初航篇章。
- 管理端 `/admin/achievements` 配置现金开关、里程碑奖励开关、已核验账户试点名单和日/月预算；写入沿用管理鉴权、二次验证和审计。

## 现金试点

迁移默认关闭全部现金。管理员核验账户后将其加入试点名单，最多 100 个账户。账户需在近 30 日有仍有效的净充值，或近期余额计费使用。完全退款且没有余额消费时不再满足资格。预算按签到与成就发奖原额共同累计，退款不释放预算。

历史成长回填与 opening 初始成长不作为近期充值依据；在线充值同时核验原订单的实际支付时间，历史管理员回填按来源排除。初始试点保守排除历史回填，不因账本录入时间为“今天”而授予现金资格。

每日预算 0–1000 USD、月预算不少于日预算且不超过 10000 USD。测试环境使用单独测试账户验证发奖，不自动开放其他账户。关闭现金时仍可记录签到、通过活动、收集和佩戴；同日先签到再开通现金或升级不会补发当日奖励。

每日记录 `(user_id, day)`、请求 `(user_id, request_key)` 均唯一。已提交请求的重试返回原回执；新请求的预期日期与服务器不一致时要求刷新。所有发奖先锁配置和用户，预算预占、到账、回执共用事务。余额入账使用独立更新，不经过管理员充值调整入口。

## 用户接口

接口均位于 `/api/v1`，沿用项目标准响应封装和 JWT 用户鉴权。

| 方法 | 路径 | 内容 |
|---|---|---|
| GET | `/user/achievements` | 服务器日期、权益、日历、历史、全部徽章进度和佩戴 |
| POST | `/user/achievements/checkin` | `date`、`request_key`；签到回执 |
| POST | `/user/achievements/claim` | `key`；成就领奖回执 |
| POST | `/user/achievements/equip` | `key`；空字符串卸下 |
| GET | `/user/achievements/activity/topics` | 可用主题 |
| GET | `/user/achievements/activity/:kind/:topic` | 不含答案键的题目 |
| POST | `/user/achievements/activity/:kind/:topic` | `answers`、`request_key`；成绩与通关结果 |
| GET / PUT | `/admin/achievements/config` | 读取 / 保存奖励试点配置 |

领奖重复请求返回历史回执，不再次修改余额。已追回的回执保留追回时间，界面显示“已追回”。活动相同请求编号但内容不同返回冲突；响应丢失后先重试原始答案，需要修改时显式开始新尝试。

## 验收要点

1. 页面初始为签到，四个栏目、21 枚 v2 徽章和深浅色显示正常。
2. 实际签到、刷新页面后记录仍在；同日连续点击和多端并发不会重复到账。
3. 六档每日金额与服务端权益一致；VIP 关闭、人工展示等级、先签到后升级不会错误提升奖励。
4. 现金关闭、名单外、近期活动不足、预算耗尽显示真实原因；零奖励签到仍保留成长记录。
5. 有待追回金额时原额、抵扣和净到账可核对，奖励不会增加充值或邀请返利。
6. 成就并发领取仅一次；充值退款锁定荣誉并追回相关奖励，重复退款及再次充值不重复发奖。
7. 活动由服务端评分，不同主题去重，初航四项完成后篇章入册；重复请求、篡改同一编号内容、超过尝试上限正确处理。
8. 刷新后佩戴和进度保持，账户之间数据隔离，匿名和普通用户不能读取或保存管理配置。
