# 成就收藏册

**敬请期待。** 成就系统正在规划，当前没有解锁、领奖或佩戴入口。

## 收藏每一次成长

围绕调用用量、持续参与、活动探索和累计充值，规划四类、18 枚成长勋章。用克制的金属纹理与品牌雕刻，让每一次达成留下可收藏的身份印记。

| 类别 | 玩法方向 | 状态 |
| --- | --- | --- |
| Token 成长 | 三档用量里程碑 | 敬请期待 |
| 持续参与 | 三档连续签到与全勤 | 敬请期待 |
| 活动探索 | 排行榜、答题、盲盒及收藏进阶 | 敬请期待 |
| 充值荣誉 | 三档累计充值成就 | 敬请期待 |

## 解锁、领取与佩戴

规划保留自动点亮、进度展示、详情查看、手动领取一次奖励与选择一枚勋章佩戴。已领取成就的展示或动画不重复发奖。

待领取数量提醒、历史数据核算和头像／资料页展示，也属于后续建设范围。本页不表示这些功能已经存在。

## 与 VIP 分开成长

VIP 由累计有效充值决定；Token 使用与活动成就不能代替充值升级。成就奖励若发放为赠送余额，不计入 VIP 成长额。

充值成就与现有 1% 累充奖励的关联方式、退款后的荣誉与奖励处理，在正式上线前公布，避免同一里程碑重复承诺奖励。
