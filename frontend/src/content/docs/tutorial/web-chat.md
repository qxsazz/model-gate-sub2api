# 在线对话

在网页里提问、追问或让模型看图，都使用你自己在本站创建的 API 密钥，用量计入所选密钥。

## 开始对话

1. 打开[在线对话](/chat)，点左下角「对话设置」选择密钥。只有一把可用密钥时会自动选中。还没有密钥，可以到 [API 密钥](/keys) 创建。
2. 点发送箭头左侧的模型名称，选择这把密钥可用的 GPT、Gemini、Claude 或其他模型。列表为空时，请换一把有对话权限的密钥。
3. 输入问题，点发送箭头。收到回答后可以继续追问，也可以点「新对话」换个话题。

## 让模型看图

选择支持识图的模型，点「添加图片」。直接发送可以让模型描述画面，也可以附上问题，例如「截图里的报错出在哪一步？」

支持 PNG、JPEG、WebP。每条消息最多 3 张，合计不超过 4 MiB。想根据文字或参考图生成新图片，请看[网站生图](/docs?cat=tutorial&page=image-generation)。

## 找回之前的对话

在「对话记录」中查看当前账户、当前密钥下的会话。换过密钥时，先切回原来的那一把。

每段会话从**最后一次成功收到回复**起保留 **5 天**，到期后服务器会清理消息和图片。只打开记录不会延长时间。重要的回答或图片请提前保存，也可以用「删除对话」提前清除。
