# MODEL-GATE 无限画布

## 用户入口与凭据

登录后从左侧「无限画布」进入。主站 Vue 页面嵌入独立构建的 React 画布，保留主站导航，画布使用 MODEL-GATE 的香槟金、暖白、墨黑主题，并跟随主站明暗模式。

栏目内提供原项目的「首页」「生图工作台」「视频工作台」「我的画布」「素材库」「提示词库」「配置」页面入口，保留主站侧栏，默认打开生图工作台。独立工作台可直接输入提示词、上传参考图并生成，无需先创建画布节点。生成历史的元数据与私有素材引用按账号保存到云端，可刷新恢复；点击结果上的加入素材库按钮，可在同栏目素材库与画布中继续使用。

页面不再重复展示标题、保存状态、全局模型选择和刷新 Key 栏。模型选择放在各工作台和配置页的「偏好设置」中；渠道页自动同步本站 Key 对应的 OpenAI 与 Google 原生协议渠道，可选择模型和调整能力分类。生成偏好和模型选择按账号保存，不保存完整模型 Key。配置文件导出也不包含模型 Key 或 WebDAV 密码，导入不会替换本站托管渠道。

图片、视频各自选择模型及用户 Key；缺少对应 Key 或模型时显示创建入口。画布提供生图、视频、文本三个创建入口，跳转到主站同一 API 密钥表单并预选用途，创建成功返回画布；记录与主站 API 密钥列表统一。用途只筛选创建时已授权的分组，不另建 Key 存储或改变分组实际权限。前后端均校验用途，专属分组仍须充值达标或后台授权。完整 Key 不进入画布配置、URL 或 postMessage；画布只发送 Key ID，由后端验证归属后调用现有网关，保留权限、余额、IP 规则、调度与用量计费。

支持主站 OpenAI 风格图片生成和编辑、Google 原生 Gemini `generateContent` 文生图/参考图编辑，以及 Grok 视频生成、轮询、内容下载。Google 图片的 inlineData 在后端归档后改为私有引用，保留文本、usage 和 thoughtSignature；Google 分组、Antigravity 分组和聚合分组均按现有权限判断原生协议能力。画布文本节点也可通过托管文本接口调用模型，音频结果同样归档。未接入的模型协议不会因上游画布支持而自动可用。提示词源支持公开 HTTPS JSON 并恢复定时刷新；配置页保留 WebDAV 同步和本地缓存统计，WebDAV 使用用户配置的 HTTPS 服务并遵循该服务 CORS 策略，密码仅用于当前会话。用户导出到自己的 WebDAV 的副本由用户管理，不属于本站的七天素材归档。本地代理页说明本站服务器已代为连接模型服务。托管版关闭外部模型渠道配置、远程节点插件、自定义执行脚本和本地 Agent。

## 云端数据与七天素材生命周期

- PostgreSQL 的 `canvas_states` 按认证用户保存画布结构和素材引用；乐观版本检查防止不同窗口互相覆盖。冲突或保存失败时显示错误并暂停自动写入，刷新后重新加载。
- 素材保存在持久化数据目录 `canvas-private/`，位于静态资源目录之外，文件权限为 0600。默认 Docker 数据卷已有持久化，无需额外对象存储配置。
- `canvas_assets` 记录用户、提示词、模型、来源、Key ID、审核状态、创建和到期时间；`canvas_asset_bindings` 将画布引用绑定到素材。相同用户的相同文件共用素材、保存期限和审核状态，不跨用户去重。
- 图片、参考图、视频及音频从首次归档成功起保存 168 小时；再次引用不会延长期限。到期即拒绝读取，后台每分钟重试物理删除。服务停机时无法执行文件清理，重启后会继续；停止服务期间也不会对外提供访问。
- 画布结构保留，图片不可用时展示占位图。文件不写入画布 JSON 或浏览器 IndexedDB；浏览器仅持有当前页面的临时 Blob URL。用户自行下载的副本不受网站清理影响。
- 视频任务保存在数据库，后台继续轮询和归档，页面关闭或服务重启后仍可继续。网关原有完成计费去重继续生效。

当前存储方案面向现有单实例、单数据卷部署。横向扩容前需要共享私有文件卷或实现对象存储读写、删除适配，并统一清理任务调度。数据库备份不包含媒体文件；不要将私有素材目录加入长期备份，否则备份副本需要独立执行七天生命周期规则。

## 事后审核

管理员进入「画布内容审核」，按用户 ID 和审核状态筛选，查看用户、提示词、模型和到期时间，点击预览后加载私有内容。管理员查看、标记正常、屏蔽、恢复待审核均记录在 `canvas_reviews`；屏蔽要求备注。普通用户无法读取他人作品，屏蔽后原地址和所有素材引用均拒绝访问。审核不会延长七天期限，也不新增生成前拦截。

后台沿用主站管理员认证与现有合规确认门槛。主站的现有全局网关规则继续生效。审核无法收回用户已经下载或当前页面已经加载的副本。

## 构建与测试环境

`canvas/UPSTREAM.md` 固定来源提交并保留 MIT 许可及作者标识。Docker 使用 Node 24 单独构建 `canvas/web`，将产物放入主站嵌入目录的 `canvas-app/`。同源嵌入响应头只对该路径开放，其他页面仍禁止被嵌入。

本地构建：

```sh
cd canvas/web
npm ci
npm run typecheck
npm run build
cd ../../frontend
pnpm run build
cd ..
cp -a canvas/web/dist backend/internal/web/dist/canvas-app
cd backend
go build -tags embed ./cmd/server
```

测试环境沿用针对 `staging` 的 PR 自动构建和部署。镜像同时包含主站和画布，不增加公网端口或测试服务器配置。数据库启动时自动执行迁移 254，已有数据卷用于私有文件。

验收覆盖：原项目七个页面入口、配置云端恢复、Google 原生模型列表/文生图/参考图编辑与审核归档、无 Key / 单能力 Key 提示、创建后刷新、画布新建与刷新恢复、图片生成与编辑、视频生成与归档、跨账号拒绝、七天到期与文件清理、审核屏蔽、明暗主题与嵌入路径刷新。

### Key 分组权限核验

测试环境 VIP 自动访问门槛为累计有效充值 100 美元，专属生图分组、gemini专属生图均为专属且启用 VIP 访问；后台手动授权沿用现有权限。普通用户只返回公共分组，直接伪造专属 group_id 也被服务端拒绝。分组用途基于实际生成权限、平台和模型白名单计算，不依据名称猜测。

迁移 255 修正已有明确标注“只可聊天使用”的 Grok 分组：关闭媒体生成并启用文本模型白名单，保留现有文本模型和网关正式文本别名。鉴权快照版本升至 25，使旧缓存重新读取修正后的权限。测试环境部署后自动以只读 SQL 核验这些配置。

### 生图任务与后台删除

迁移 256 增加 `canvas_generation_tasks`，画布与工作台通过本站认证提交持久化任务。兼容 OpenAI 图片生成/编辑和 Gemini 原生 generateContent；继续走原网关权限、额度、IP 规则及计费，不依赖上游原生异步能力或通用异步接口的 S3 开关。每次提交使用固定 UUID 防重；每账号最多 20 个待处理任务，4 个后台 worker 用数据库原子领取，完成后清除输入请求。任务记录保留七天。

画布节点及任务关联先确认保存后再提交。切换子页面、主站栏目或刷新后恢复任务、工作台历史及原画布节点，结果支持在「生成任务」中查看。各生成槽和任务面板共用状态轮询。排队任务可以取消；执行中的停止为尽力中断，上游状态不明时标记中断，不自动重发，避免重复计费。worker 定期心跳，失联运行任务在约两分钟后转为中断；尚未领取的排队任务可在服务重启后继续执行。

后台审核页面支持填写原因后删除素材。删除先在事务中标记不可用并记录审计，再移除私有文件；文件清理失败由原清理 worker 重试。画布、历史和素材库别名全部遵循同一素材标记。删除与相同内容的上传通过同一锁串行，在原保存期限内拒绝缓存副本重新上传；保留操作元数据，不保留图片副本。原七天到期机制继续生效。

迁移 257 清除既有通用审计中的画布请求正文，保留操作者、路径、状态等操作信息；新请求同样不采集正文，避免参考图或配置备份成为额外的图片副本。后台审核/删除原因及 `canvas_reviews` 审计记录继续保留。
