# 成就收藏册

打开[成就与签到](/achievements)就能签到、查看进度和佩戴徽章。收藏册共有四类、21 枚徽章。

| 我想做什么 | 可以获得什么 |
| --- | --- |
| [每日签到、查看到期余额或补签](/docs?cat=achievements&page=check-in) | 3 枚连续签到徽章 |
| [查看付费文本 Token 用量](/docs?cat=achievements&page=token) | 6 枚用量里程碑徽章 |
| [核对累计有效充值](/docs?cat=achievements&page=collection) | 3 枚充值荣誉徽章 |
| [参加知识挑战和实践演练](/docs?cat=achievements&page=activities) | 9 枚活动勋章，其中 2 枚为后续篇章预告 |

## 解锁、领取与佩戴

点开徽章可以看还差多少进度。解锁后可选一枚佩戴，也可以随时换戴。领取奖励需另点「领取」，每项限领一次。活动勋章可领补签卡，集齐系列后可查看整套奖励。

领取成就金额还需近 30 天有符合条件的充值或余额消费。奖励开放时可在页面查看资格和到账金额。签到、成就奖励都不计入 VIP 充值成长。VIP 中心的五档奖励可在[累充奖励](/docs?cat=membership&page=rewards)中查看。
