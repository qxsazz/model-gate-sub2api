# MG 品牌默认值

MG 默认身份为 `MODEL-GATE`。已有自定义网站名称和 Logo 继续生效；本次调整不批量改写数据库中的网站配置，也不改动 Go module、包名或服务技术标识。

## 配置规则

| 配置或页面 | 未配置时 | 已配置时 |
|---|---|---|
| `site_name` | 空值或纯空白使用 `MODEL-GATE` | 保留自定义名称，去除首尾空白 |
| 控制台、紧凑首页、联系页、Key 用量页、模型广场及法律页 Logo | 使用 `/model-gate-mg-luxury.svg` | 使用已配置、通过 URL 校验的 Logo |
| 浏览器 favicon | 使用 MG SVG | 使用已配置、通过 URL 校验的 Logo |
| Auth 页面 Logo | 不显示占位 Logo，也不回退到 MG Logo | 设置加载后显示已上传 Logo |

已有非空名称，包括 `Sub2API`，属于已配置值，不会因默认值调整而自动更名。Auth 页面的网站主标题同样采用配置名称；页面中的 MG 授权说明保留。文档页和首页控制台预览也使用统一的 MG 默认图标。

首页表格项指 `compact_home_enabled` 启用的紧凑首页。完整 MG 营销首页本次保持既有固定品牌内容，自定义名称和 Logo 不会替换其全部品牌展示。

## 修改与恢复

在管理侧网站设置中修改网站名称或上传 Logo，保存后重新加载页面，确认侧栏、公共页、登录页及浏览器图标的实际显示。

清空网站名称后，页面和后端网站名称读取使用 `MODEL-GATE`。清空 Logo 后，上表列出的页面恢复 MG Logo，浏览器 favicon 恢复 MG SVG，Auth 页面移除 Logo。配置加载时，favicon 会同步处理空值，因此清空 Logo 后不会继续沿用先前的自定义图标。

自定义 Logo 沿用现有 URL 校验规则。无效地址不会被渲染为页面 Logo；只有通过校验的地址会被写入 favicon。建议通过设置页上传并保存 Logo，而非直接写入未经验证的 URL。

## 验收要点

- 空名称、纯空白名称显示 `MODEL-GATE`，自定义名称在侧栏、登录主标题和浏览器标题中保留。
- 无自定义 Logo 时，上表列出的页面显示 MG Logo，Auth 页面不显示 Logo。
- 上传自定义 Logo 后，相关页面与 favicon 使用该 Logo。
- 清空 Logo 后，favicon 与上表列出的页面恢复 MG，Auth 页面不再显示原 Logo。
- 明暗模式及移动端显示保持现有布局。

MG 后台版本入口及发布、回滚操作见 [CI/CD 发布操作手册](cicd-release-runbook.md#11-mg-后台版本入口)。品牌配置不改变托管发布策略。
