# 成就收藏册

测试环境的「成就与签到」页面读取真实账户记录，默认展示签到。当前收藏册包含四类、21 枚徽章，保留已确认的虚拟背景 v2 金属雕刻图案。

## 收藏每一次成长

| 类别 | 成长条件 | 徽章数 |
| --- | --- | --- |
| 签到 | 最长连续 100、199、365 天 | 3 |
| Token 成长 | 100 万至 1,000 亿付费文本 Token | 6 |
| 充值荣誉 | 累计有效充值 $1,000、$5,000、$10,000 | 3 |
| 活动探索 | 知识、实践及不同篇章收集 | 9，其中 2 枚后续篇章预告 |

## 解锁、领取与佩戴

服务端核验条件后点亮徽章，并展示真实进度。已解锁徽章可直接佩戴一枚；换戴、卸下或重新打开页面不会发奖。佩戴与活动通关记录按账户保存。

现金奖励默认关闭。管理员可选择全体符合资格账户或核验名单，成就发奖开关与签到开关独立；满足开放范围、近期活动资格及已启用的实时限额时，可手动领取已解锁签到、Token、充值徽章的金额及集齐活动系列的金额，成功后立即到账。活动单枚勋章发补签卡，每系列三枚分别 1/2/3 张；领取卡片不要求近期充值或消费，集齐系列才发金额。每个账户每枚徽章终身只领取一次，重复请求返回原回执。待追回金额会先抵扣，回执显示原额与净到账。

管理员可人工授予徽章并选择同时发放尚未领取的奖励。取消默认只撤销徽章，也可明确选择追回奖励；恢复自动条件不会重置已领取资格。操作保留原因与审计记录。

## 与 VIP 分开成长

VIP 由累计有效充值决定；Token 使用与活动成就不能代替充值升级。签到与成就奖励不计充值成长，不产生邀请佣金。

充值荣誉奖励与 VIP 五档累充奖励分别管理。退款可能锁定不再满足条件的充值荣誉并追回对应奖励；已追回的领取记录保留，以后再次充值也不重复发奖。
