# 充值与兑换

充值提供账户可用余额，也为会员成长积累有效金额。兑换与赠送余额可以用于符合条件的服务，但与实际充值的成长计量不同。

## 在线充值

进入控制台的充值入口，核对金额、支付方式、订单币种与说明，完成付款后查看订单状态和余额。仅使用当前页面实际开放的支付方式，不通过陌生收款链接充值。

支付成功与订单确认之间可能有短暂延迟。若长时间未到账，保存订单号、付款时间和状态截图，脱敏后联系平台；不要因页面暂未更新而连续重复支付。

## 兑换余额

在兑换页面输入兑换码，注意大小写与使用次数。兑换所得余额不计入 VIP 累计有效充值，不能把“余额增加”直接理解为“会员成长增加”。

## 后台调整

按当前会员规则，后台手动增加的金额计入累计充值；后台退费减少成长金额，并重新计算自动权益。余额、成长额和有效等级分别显示，可能不相同。

## 币种与计量

会员方案按 USD 计量。当前确认的平台成长规则为 **1 CNY = 1 USD 成长额**，这是一项平台成长换算规则，不是市场外汇报价。

例如 VIP 5 实付 100 CNY、5% 加赠后到账 105 单位余额，VIP 累计额只增加 100。成长加赠启用时普通会员 0%，VIP 1–5 为 1%–5%，以下单时等级计算；升级后的比例从下一笔订单生效。新订单保存换算和加赠快照，之后调整规则不改写该订单或已到账余额。签到尚未上线，不属于当前充值赠送。

历史充值订单不自动回填。需要根据订单、退款与既有成长流水核对后补录，不能将当前余额或含加赠的到账金额直接当作历史有效充值额。

## 核对四项信息

| 位置 | 核对内容 |
| --- | --- |
| 订单 | 支付是否完成、币种与金额是否正确 |
| 账户余额 | 可用余额是否变化 |
| VIP 中心 | 累计有效充值及下一档差额 |
| 累充奖励 | 是否产生新的可领取档位 |

退款后的等级与奖励处理请阅读 [VIP 权益](/docs?cat=membership&page=vip)和 [累充奖励](/docs?cat=membership&page=rewards)。
