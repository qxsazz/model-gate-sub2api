# 成就奖励与补签卡

已确认的测试环境规则：

- 签到条件保留连续 100、199、365 天，奖励为 5、12、30 USD。
- Token 条件保留六档，奖励为 0.10、0.50、2、8、25、80 USD。
- 充值条件保留 1000、5000、10000 USD，奖励为 10、50、666 USD。
- 活动知识、实践、篇章三个系列的三枚勋章分别奖励 1、2、3 张补签卡，手动领取、终身一次。
- 集齐系列全部三枚已开放成就后，分别可领取知识 1.40、实践 2.30、篇章 11.80 USD，终身一次。篇章后两枚继续预告，不提前开放。
- 补签卡可补北京时间今天之前最近 30 天的漏签，允许跨月，不补注册前日期。
- 补发漏签日历史 VIP 签到金额；历史资料缺失不猜测等级。预览与执行核对金额、等级；当前签到现金开关、范围和可选实时限额仍生效。
- 扣卡、补签、金额入账、余额抵扣、连续记录重算在同一事务执行；服务端校验未通过不扣卡，网络中断时按原请求重试或刷新查询回执。已签到不扣卡、不重复发奖；相同请求编号只执行一次，换日期复用编号拒绝。
- 补签卡不可转让、不可直接兑换余额，没有到期时间。使用时按领取顺序扣除，保留来源与使用记录。
- 金额发放沿用领取后即时入账，每枚/系列终身一次，佩戴不发奖。现金开关不影响正常账户领取已解锁活动勋章的补签卡。
- 历史金额回执不重算，不自动补差额；活动勋章旧现金保留并抵扣对应系列的新现金总额，防止同一系列重复金额。新补签卡每枚单独领取一次。
- 管理员授予活动勋章并发奖时发补签卡；取消默认仅撤勋章，明确追回奖励时回收未用补签卡，已使用卡片及已形成的签到记录保留；若对应系列金额已领取且明确追回，按既有现金追回方式处理。领取记录不重置。

验证重点：六档金额、完整系列而非单枚发现金、现金关闭仍可领卡、卡片终身一次、历史权益、跨月、日期范围、注册日期、预览变化、重复请求与并发、预算校验未通过不扣卡、管理操作及历史迁移。
