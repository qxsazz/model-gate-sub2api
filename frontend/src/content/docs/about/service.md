# 了解 MODEL-GATE

MODEL-GATE 为模型调用提供统一入口，将访问密钥、模型分组、计费用量与会员权益组织到同一账户中。

## 我们提供什么

| 服务 | 你可以做什么 |
| --- | --- |
| 多协议接入 | 按模型和分组选择 OpenAI、Anthropic 或 Gemini 兼容入口 |
| 分组与密钥管理 | 为不同应用分配独立密钥，选择适合任务的渠道 |
| 用量与计费查询 | 核对请求、Token、有效倍率与实际费用 |
| VIP 成长 | 按累计有效充值查看会员身份与对应权益 |
| 故障排查 | 结合响应、用量和开放的错误记录定位问题 |

## 我们的服务原则

**接入清晰。** 不把不同协议、分组与模型能力混为一谈，不承诺某个模型永久可用。

**计费可查。** 普通分组成长减免与专属分组独立价格分别说明，以实际有效权益和使用记录核对费用。

**故障可追踪。** 区分用户配置、额度限制、网络异常和上游故障，不把所有问题都归咎于密钥或余额。

**安全有边界。** 密钥保护、账户归属校验和受限记录视图是服务底线，同时明确客户端、平台与上游各自的数据处理边界。

## 安全与隐私是服务底线

我们不要求你公开完整 API Key、私人提示词、代码仓库或付款凭据来获得帮助。排查从必要且经过脱敏的信息开始。

阅读 [安全与隐私 · 服务底线](/docs?cat=about&page=security)，了解凭据、请求与记录的保护方式。
