# API Key

API Key 是客户端访问 Model-Gate 的凭据。它应当像密码一样被保护。

## 创建密钥

在控制台的 API Keys 页面创建密钥。建议按照设备或用途分别创建，例如“个人电脑 Codex”和“测试环境服务”，便于后续审计与撤销。

## 保存密钥

优先使用环境变量、操作系统凭据存储或部署平台的 Secret 功能。不要把密钥写入前端代码、截图、公开仓库或共享文档。

```text
MODEL_GATE_API_KEY=mg_sk_example
```

## 最小权限与隔离

- 不同环境使用不同密钥。
- 不与他人共享个人密钥。
- 只在可信设备上保存长期凭据。
- 怀疑泄露时立即撤销并创建新密钥。

## 轮换密钥

先创建新密钥并更新客户端，确认请求成功后再撤销旧密钥。这样可以避免切换期间出现中断。

## 常见错误

收到 `401` 时，先检查请求头是否使用 `Authorization: Bearer <API_KEY>`，再确认密钥未被撤销、没有多余空格，并属于当前站点账户。
