## 保留 MG 定制

- 保留品牌、主题、主站布局、自定义站名、VIP、签到、成就、累计实付充值门槛、画布、私有素材审核、分组计价和托管更新入口。
- 保留 Gemini 多账号模型汇总、思考与正文独立处理、签名回放及降级重试规则；接入官方的累计文本构建器和有界 SSE 读取。
- 保留网关恢复队列、HTTP/WS 重试边界、并发槽位释放、在途预留引用计数、画布托管图片的取消与超时保护。
- 保留 VIP 请求价格快照、严格倍率校验、Fast 策略、成就媒体计数和缓存存储价格快照；接入官方的异步用量上下文隔离、配额持久化和通知任务。
- 官方抽取 OpenAI 透传规则后，在新路径中继续标记 MG 自定义错误文案，防止再次被通用客户端错误改写。
- 保留 Node 24、画布合并构建、MG 安全依赖与 overrides；新增 MCP SDK/Moego 依赖和官方安全约束，不降级已有 `x/image`、Brotli 或 compress。
- 保留测试分支直接推送部署、候选提交先通过五项检查、生产通过 PR 审核及人工晋级同一镜像的发布机制。

`canvas/` 的 338 个已跟踪文件与原 MG 版本逐字节一致；35 个原有品牌素材保持一致，不引入上游新增推广素材。README 英日版保留 MG 原文，中文版仅补入图片 2.6 功能说明。CC Switch 新增的内嵌 Codex 配置使用实际站名，保留中文、引号和反斜杠。

## 权限与数据库兼容

- 普通受限管理员密钥仍按精确权限目录授权，未登记的 MG VIP、成就、画布及提示词审核接口默认拒绝。
- 官方新增 `full_access` 模式默认关闭；创建或升级为全权必须显式确认。明确确认的全权密钥可以使用 MG 管理接口，但不能管理管理员密钥，并继续经过合规、审计与限流保护。
- MCP 使用官方静态工具目录与既有管理守卫，不自动将 MG 扩展路由、插件或任意 URL 暴露为工具。禁用/降级用户及撤销会话时，保留官方 MCP 授权撤销行为。
- 保留 318 个原有 SQL 文件的文件名和内容。`249_achievement_administration.sql` 与官方 `249_mcp_oauth.sql` 按完整文件名分别记录，允许并存，不重命名已应用迁移。
- 鉴权快照升为版本 27：保留 MG 利润、倍率、Fast、图片按张计费及 Codex 清单字段，并加入官方隐私门和 RPM 查询状态字段；旧版本 25/26 回源重建。

## 官方新增行为与资源保护

- 合入管理 MCP/OAuth、全权密钥显式确认、邮箱黑名单、图片尺寸筛选、OpenAI 图片 2.6、用量导出限流与读取保护。
- MCP 默认关闭，按官方 [MCP 文档](mcp.md) 配置 `MCP_PUBLIC_URL` 后启用；不改变 MG 后台模式的用户路由限制。
- 采用官方请求体内存预算、逐次读写 deadline、有界 SSE 及 drain。Zstd 请求解压窗口按官方收紧为 8 MiB；保留解压超限错误及禁止成功截断的行为。
- 通用请求体总预算默认 1 GiB；测试容器维持 768 MiB 内存和原 CPU 限制，使用独立 `STAGING_GATEWAY_REQUEST_BODY_MEMORY_BUDGET_BYTES`，默认 256 MiB。
- 内存预算包括分块数据、连续副本和解压工作区；256 MiB 总预算不等于保证接收任意 256 MiB 请求。资源不足按官方语义返回可重试错误，不修改生产通用默认值或 SSE 大行兼容上限。
