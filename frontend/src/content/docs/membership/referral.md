# 邀请返利

分享自己的邀请入口，并在邀请返利页面核对邀请关系与结算记录。会员成长可以提高当前有效返利比例。

## 等级对应比例

| 等级 | 默认返利比例 |
| --- | --- |
| 普通会员 | 0% |
| VIP 1 | 2% |
| VIP 2 | 4% |
| VIP 3 | 6% |
| VIP 4 | 8% |
| VIP 5 | 10% |

平台可能存在人工设置，以账户当前有效比例为准。返利比例不是普通分组倍率优惠，也不是自己充值的加赠比例。

## 使用步骤

1. 在邀请返利页面取得自己的邀请链接。
2. 对方按邀请流程建立关系后，在记录中核对。
3. 查看符合返利条件的交易、结算状态与到账明细。

不是每个注册或每次余额变化都会产生返利。具体返利基数、结算条件、冻结与可用状态以邀请返利页面的实际规则为准。

## 与会员成长的关系

邀请奖励不计入自己的累计有效充值。退款、退费导致有效 VIP 等级变化时，后续适用比例可能随之变化；不应把历史某一档比例理解为永久保证。

不要通过虚构交易或多个自用账户制造返利，异常交易以平台核查结果为准。
