# 网站生图

登录后打开[无限画布](/infinite-canvas)，就会进入「生图工作台」。生成图片使用你在本站有生图权限的 API 密钥，费用可在「使用记录」中核对。

## 生成第一张图

1. 点「调整」选择图片模型。列表为空时，点「创建生图 Key」，选择支持生图的分组，再返回工作台。
2. 在「提示词」写下想要的画面，例如「水彩插画，一只橘猫坐在雨后的窗边，横向构图」。想修改已有图片时，可以在「参考图」里点「上传」，再写明希望保留或改变的地方。
3. 点「开始生成」。离开页面后，可以回来打开「生成任务」查看进度。出图后点「下载」保存原图，或点「加入参考图」继续修改。

如果侧栏里有「批量生图」，还可以一起提交多条提示词，完成后下载 ZIP。[打开批量生图](/batch-image)

## 图片能取回多久

画布里的参考图和生成图片从首次保存起可取回 **7 天**。再次引用或加入素材库都沿用原到期时间。要长期保留作品，请在到期前下载。[查看数据保存说明](/docs?cat=about&page=security)
