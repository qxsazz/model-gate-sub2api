# 安全与隐私 · 服务底线

站内对话和画布素材按账户隔离。你可以删除自己的对话，也可以把想保留的作品下载到自己的设备。

## 聊天和图片会保存多久

- **在线对话**按账户和密钥分别保存消息及附件。从最后一次成功收到回复起保留 **5 天**，到期后自动清理。你也可以在「对话记录」中点「删除对话」，连同该会话的图片一起删除。[在线对话指南](/docs?cat=tutorial&page=web-chat)
- **无限画布**中的参考图和生成图片从首次保存起保留 **7 天**。到期后无法再从站内读取，后台会清理文件。画布结构和提示词可以保留更久。想留下原图，请提前下载。[网站生图指南](/docs?cat=tutorial&page=image-generation)
- **批量生图**使用单独的保存规则。任务结束后，输入文件的默认清理期限是 24 小时，输出文件是 72 小时，实际期限取决于站点配置。下载到自己设备上的副本由你管理。

## 账户与使用记录

网站保存注册邮箱、订单、余额和调用用量，用于登录和费用核对。错误和安全记录可能包含请求时间、IP 地址、提示词或错误详情，按各自的规则保存。

使用模型时，本次请求所需的文字或图片会发送给模型服务。该服务按自己的规则处理数据。

## 凭据保护

通过 HTTPS 使用本站。反馈问题时，提供时间、请求 ID 和报错截图即可。截图中请先遮盖个人信息、完整密钥、密码和验证码。发现密钥泄露时，可在「API 密钥」中停用它，再到「使用记录」核对调用。[查看记录与反馈问题](/docs?cat=troubleshooting&page=records)
